# /verify — 최종 점검

오케스트레이터가 수행한다. 아래를 순서대로 확인하고 하나라도 실패하면 /run 5단계(보완)로 돌아간다.

## 체크리스트
1. **계획 대비 완료**: docs/PLAN.md 의 모든 태스크가 체크되어 있는가. 안 된 것이 있으면 이유가 "범위 밖" 으로 명시되어 있는가.
2. **테스트**: tester 에게 "전체 테스트 실행" 을 위임해 PASS 를 받는다. 오케스트레이터가 직접 돌리지 않는다.
3. **실행 확인**: 프로젝트 유형에 맞는 스모크 테스트 1회 (빌드 성공 / 서버 기동 / 스크립트 실행 / 문서 렌더링). builder 또는 tester 에게 위임.
4. **리뷰 게이트**: reviewer 에게 "최종 리뷰: 전체 변경 사항을 PLAN.md 기준으로 판정" 을 위임해 PASS 를 받는다.
5. **정리**: 임시 파일, 디버그 출력, 하드코딩된 비밀값이 없는지 builder 에게 확인 위임.
6. **문서**: README 또는 실행 방법이 사용자가 바로 따라할 수 있는 수준인가.

## 결과 기록
docs/STATUS.md 에 다음을 추가한다:
```
## 최종 검증 (<날짜>)
- 테스트: <통과 N / 실패 0>
- 리뷰: PASS
- 스모크: <무엇을 어떻게 확인했는지 한 줄>
- 알려진 제한: <있으면>
```
