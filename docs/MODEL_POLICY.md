# 구독 기반 지휘자 선택

정책은 `best_available_subscription`입니다. 지휘자는 사용자의 **현재 인증 계정과 구독**에서
실제로 선택할 수 있는 모델 중, 도구 사용과 복잡한 추론·코딩 역량 순위가 가장 높은
모델입니다. 특정 공급자·모델 버전·가격을 코드에 고정하지 않습니다. 최신 이름이나
기본 모델이라는 이유만으로 최고 성능이라고 판단하지 않습니다.

## 확인과 순위

실행 환경의 모델 선택 화면·공식 계정별 카탈로그에서 실제 사용 가능 여부를 확인합니다.
공개 API 모델 목록, 웹 문서 또는 CLI 설치 여부만으로 구독 권한을 추정하지 않습니다.
인증 토큰·비밀번호·API 키는 읽거나 inventory에 넣지 않습니다. 모든 공급자의 구독을
조회하는 공통 API는 없으므로 이 템플릿은 로그인/권한 탐색을 가장하지 않습니다.

지휘자 또는 사용자가 확인한 목록을 `.harness/local/models.json`에 기록합니다.
CLI가 검증·선택·선택 근거 저장·실행 명령 생성을 담당합니다. 현재 도구가 모델 목록을
제공하지 않으면 모델 선택 화면의 목록을 확인해야 합니다. 확인 자료가 없으면
모델 선택을 BLOCKED로 보고하고 필요한 목록을 요청하세요. 자동으로 현재 모델을
최고라고 부르거나 과금 방식을 바꾸지 않습니다.

```json
{
  "version": 1,
  "observed_at": "실제 확인한 현재 UTC 시각 (ISO 8601)",
  "source": "확인한 계정의 runtime model picker 또는 지원 catalog 명령",
  "models": [
    {
      "runtime": "codex",
      "id": "실제 선택 가능한 모델 ID",
      "available": true,
      "billing": "subscription",
      "supports_tools": true,
      "capability_rank": 100,
      "rank_reason": "공식 모델 설명 또는 프로젝트 평가에서 추론/코딩 역량 상위"
    }
  ]
}
```

위 예제의 설명 문구는 실제 값으로 교체해야 합니다. rank는 클수록 우선이며 통일된
벤치마크 점수라고 주장하지 않습니다. 도구별 공식 설명과 프로젝트 평가로 근거를
남기세요. 공급자 간 우열을 판단할 자료가 부족하면 `--runtime`으로 현재 사용할
도구에 한정합니다. 동률은 runtime·ID 사전순으로 결정해 재현성을 유지합니다.

관측 후 24시간이 지났거나 미래 시각·중복 ID·근거 누락이면 거부합니다. 계정 변경,
모델 접근 변경 또는 구독 한도 소진 시 더 일찍 갱신하세요. available=false, API 과금,
도구 미지원 모델은 제외합니다. 선택 가능한 모델이 없으면 실패하며 조용히 강등하지
않습니다. `commander_pin`은 `runtime/model-id` 형식의 명시적 사용자 선택이며 가용성
검사는 그대로 적용됩니다. pin이 설정되면 최상위 자동 선택을 덮어썼다고 기록합니다.

## 실제 실행

런타임은 `.harness/config.json`의 `runtimes`에 등록합니다. Claude/Codex/Gemini CLI
어댑터와 GUI 선택용 cursor/copilot/generic이 기본입니다. 다른 도구는 이름과 실행 argv를
추가하세요. `{model}` 인자가 선택된 ID로 치환됩니다. 빈 배열은 GUI/수동 선택 전용이고
자동 실행을 거부합니다. 외부 inventory가 임의 실행 파일을 지정할 수는 없습니다.

`route`는 구독 여부를 인증해 주는 서비스가 아닙니다. 관측 입력을 검증하고 그 안에서
선택합니다. 선택 결과와 명령은 JSON으로 출력합니다. `--launch`는 shell 없이
등록된 argv(기본 `claude --model ID`, `codex --model ID`, `gemini --model ID`)를 대화형 터미널에서 실행합니다.
로그인된 CLI를 사용하고 인증 방식이 구독인지 먼저 확인하세요. 알려진 API 인증/과금
환경 변수가 있으면 자동 실행을 거부합니다. 이를 자동 삭제하거나 사용자 인증을 바꾸지
않습니다. 저장된 인증 방식과 계정의 실제 과금 상태는 도구가 결정하므로 별도 확인해야 합니다.

GUI만 있는 환경은 출력 모델을 도구의 선택 기능으로 적용하고 실제 사용 모델을 확인합니다.
작업 중 스스로 모델을 바꿀 수 없는 에이전트는 새 실행 명령/지원되는 전환 기능을 사용해야
합니다. 모델이 변경됐다고 말만 하거나 모델 설정 파일을 고쳐 현재 세션에 적용됐다고
주장하지 않습니다. 선택된 도구가 없으면 설치·로그인 조건을 BLOCKED로 기록합니다.

작업자 기본값은 지휘자 모델 상속입니다. 비용 최적화가 필요하면 관측 목록에 있는
작업 적합 모델을 네이티브 호출에 명시할 수 있습니다. 가장 강한 모델은 지휘자로
유지하며, 리뷰어·테스터에게 선택한 모델과 검증 방법을 알려줍니다. 같은 구독의
사용량 절감 효과는 실제 측정 결과로 판단합니다.
